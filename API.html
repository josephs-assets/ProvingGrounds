Every Blueprint node the kit adds, grouped by what you are doing. Node names are the names you type in the Blueprint search box; the text is the same as the Details and node tooltips. You do not need any code: Function nodes have white execution pins, Getter nodes are green pure nodes, Event / override entries are events you add in a Blueprint child (Event Graph > right-click, or Functions > Override), and Event dispatchers are bound with Bind Event or the green box in the Details panel.

363 Blueprint nodes (functions and events). Developer tooling and internal helpers are not listed. Console commands (JumpScale, RunSpeed, CamDist, CamPitch, CamFov, Tuning) are described in the README, section 2.

1. Hero: jump, spin, slide, slam, crouch, abilities

Corridor Character

Node Kind Inputs Outputs What it does
Get Spin Chain Count Getter (pure) - Return Value (Integer) Counts the spins started from a mash press (SpinBufferWindow) since the level started; the animation restarts the spin clip when it changes.
Set Default Camera Function Distance (Float), Pitch (Float), Field Of View (Float) - The default camera: distance (cm), pitch (deg) and field of view (deg; also every camera view whose own is 0). ACorridorControl calls it.
Get Anim Set Getter (pure) - Return Value (Corridor Anim Set (object)) The anim set (mesh and clips) the hero uses; none = the mesh's own anim class.
Rumble Function Event (Name), Location (Vector) Return Value (Float) Rumbles the pad for Event (its Rumbles row) as if it happened at Location (zero: here). ACorridorBurst::PlaySfx calls it for every sound event. Returns the strength played (0: none).
Get Last Rumble Getter (pure) - Return Value (Name), Strength (Float) The last event that rumbled and how strong (after distance and RumbleScale).
Bounce Function Velocity (Float), Held Velocity (Float), Crate Bounce (Boolean) - Launches the character up off a crate: HeldVelocity when jump is held, was pressed just before landing on the crate, or is pressed within LateHighBounceWindow after. A crate bounce rises at plain gravity (not RiseGravityScale);
Start Celebrate Function - - The level end's celebration: the anim set's Celebrate plays once (on the ground), then the idle. ACorridorLevelEnd calls it.
Is Celebrating Getter (pure) - Return Value (Boolean) StartCelebrate was called (until the level is loaded again).
Start Leaving Function Direction (Vector), Replay (Boolean) - The level end screen's run out: the hero runs along Direction (flat; zero stops it) until the next level loads, and the level end's view stops following it. UCorridorLevelEndWidget::Leave calls it on Replay / Continue.
Is Leaving To Replay Getter (pure) - Return Value (Boolean) StartLeaving was called for Replay (the anim set's LeaveReplay), not Continue.
Is Leaving Getter (pure) - Return Value (Boolean) StartLeaving was called with a direction.
Mark Chased Function - - A chaser has the hero in reach: ACorridorChaser calls it every frame (a Blueprint chaser can too); the anim set's RunScared plays.
Is Chased Getter (pure) - Return Value (Boolean) MarkChased was called within the last quarter second.
Is Over Ledge Getter (pure) Drop (Float) Return Value (Boolean) On the ground with nothing under the middle of the capsule within Drop (cm): the hero stands on an edge (the anim set's Teeter).
Get Foot Surface Getter (pure) - Return Value (Name) The physical material under the feet by name, a leading "PM_" dropped (PM_Grass -> Grass); None in the air or on a floor with none. Clip notifies (Corridor Sfx) try their sound / effect name + "_" + this first (Footstep_Grass), then the plain name.
Apply Skin Function - - Puts on the saved skin (the game mode's SkinTable and ProgressSlot), or takes the last one off. Called when play starts.
Get Skin Getter (pure) - Return Value (Name) The skin worn (a row of the skin table; None: the hero's own look).
Bounce Off Enemy Function Velocity (Float), Held Velocity (Float) - Landing on an enemy (BounceComponent): like a crate bounce, but the double jump stays (no BlockDoubleJumpEffect).
Take Hit Function How (Corridor Death), Ignore Shield (Boolean) - A lethal hit: the shield companion takes it if it can (not the kinds that pierce it, nor any with bIgnoreShield), else the hero dies. Use this for hazards and enemies.
Die Function How (Corridor Death) - Kills the hero, shield or not. A death that needs the ground (squash, poison, knockback) in the air is the angel (Touch).
Get Death Type Getter (pure) - Return Value (Corridor Death) The last death's kind (the anim instance plays its clips while the hero is dead).
Get Shield Getter (pure) - Return Value (Corridor Shield Component (object)) The shield companion component on the hero (takes one lethal hit per level; level 3 = invulnerable).
Get Powers Getter (pure) - Return Value (Corridor Power Component (object)) The power component on the hero (worn power, power on / off, cooldowns).
Get Camera Director Getter (pure) - Return Value (Corridor Camera Director (object)) The camera director component: picks the active camera view and drives the camera.
On Power Pressed Function - - The power button.
On Pause Pressed Function - - The pause key: the HUD's pause menu opens (ACorridorHUD::TogglePause).
Is Cyclone Getter (pure) - Return Value (Boolean) True while the cyclone power is on.
Set Ability Enabled Function Ability (Corridor Ability), Enabled (Boolean) - Switches one ability on or off (the same bool as its Details box under Corridor | Abilities).
Is Ability Enabled Getter (pure) Ability (Corridor Ability) Return Value (Boolean) True if this ability is switched on (its Details box under Corridor | Abilities).
Get Corridor Action Getter (pure) - Return Value (Corridor Action) What the hero is doing now (one value, updated once per frame at the end of the hero's Tick). Drive your own Anim Blueprint states from it; it needs no Anim Set.
On Action Started Event dispatcher Action (Corridor Action) - An action began (Get Corridor Action changed to it). Fires after the previous action's On Action Ended, at most one frame late. The hero's Corridor Hero component fires the same events.
On Action Ended Event dispatcher Action (Corridor Action) - An action finished (Get Corridor Action changed away from it). Every On Action Started gets exactly one of these.
Get Hero Component Getter (pure) - Return Value (Corridor Hero Component (object)) The hero component the kit's actors talk to (also what you add to a character that is not this class).
Is On Ice Getter (pure) - Return Value (Boolean) True while the hero is inside an ice (slippery) volume.
Is Gliding Getter (pure) - Return Value (Boolean) True while gliding: the glide power on, Jump held, in the air on the way down (not on a mount).
Add Bullet Time Function Real Seconds (Float), Scale (Float) - Slows the whole world, the hero too, for RealSeconds of real time (e.g. a boss hit: 1 s at x0.25). Does nothing while the time power slows the world.
Is Bullet Time Getter (pure) - Return Value (Boolean) True while a bullet-time slow-down (AddBulletTime) is running.
Is Spinning Getter (pure) - Return Value (Boolean) True while the spin attack is active (always true while cyclone is on).
Get Spin Stage Getter (pure) - Return Value (Integer) Which spin is running: 0 = a plain one (or none), 1 = medium, 2 = strong (bTripleSpin).
Is Jump Held Getter (pure) - Return Value (Boolean) True while the jump button is held.
Is Dead Getter (pure) - Return Value (Boolean) True from the hero's death until it respawns.
Add Stick Input Function Right (Float), Forward (Float) - Stick input in screen terms (Right, Forward), as the gamepad gives it: along the camera, X flipped in the mirrored mode.
Respawn Function - - Back at the last checkpoint (a death calls it after the death's wait; not after a Classic game over).
Get Mount Getter (pure) - Return Value (Corridor Mount (object)) The mount being ridden (ACorridorMount sets it); while riding, the stick, jump and spin are the mount's.
On Corridor Jump Event / override Double Jump (Boolean) - Event: the hero jumped. bDoubleJump is true for the mid-air double jump.
On Spin Started Event / override - - Event: a spin attack just started.
On Jump Pressed Function - - Input entry points, also used by touch UI and the automated tests.
On Jump Released Function - - Call when the jump button is released: the held-jump rise ends there.
On Spin Pressed Function - - Call when the spin button is pressed: starts a spin (a boost while riding a mount).
On Spin Released Function - - Call when the spin button is released: a held boost (a jetboard's) ends there.
On Slide Pressed Function - - Slide on the ground (stick pushed), crouch on the ground (stick released), belly flop in the air.
On Slide Released Function - - Call when the slide button is released: a crouch ends once its minimum time has passed.
Is Sliding Getter (pure) - Return Value (Boolean) True while the hero is sliding.
Is Belly Flopping Getter (pure) - Return Value (Boolean) True during the belly flop (slide button pressed in mid-air).
Get Double Jump Count Getter (pure) - Return Value (Integer) Counts real double jumps (not crate bounces); the anim instance watches it for changes.
Get Near Miss Count Getter (pure) - Return Value (Integer) Counts near misses (bNearMiss); the anim instance watches it for changes.
Add Camera Shake Function Amplitude (Vector), Duration (Float), Frequency (Float), Yaw Degrees (Float), Perlin (Boolean), Blend Out (Float) - Shakes the camera: per-axis amplitude (cm; X along the view), a sine or Perlin oscillator at Frequency Hz, a yaw wobble, blended out over BlendOut at the end. A stronger shake replaces a running one.
