Can Double Jump Double Jump the second jump only

Can Slide Slide, Crouch slide, crouch / crawl, slide-spin burst, slide high jump
Can Slam Slam the slide button in the air
Can Wall Run Wall Run catching a Corridor Wall Run
Can Rope Swing Rope Swing grabbing a Corridor Rope Swing
Can Grind Rail Grind Rail, Rail Hang landing on and riding a Corridor Grind Rail
Can Glide Glide the Glide power's effect
Can Use Mounts Mount boarding Corridor Mount / Jetboard
Can Use Powers Cyclone, Glide wearing and switching on any power
Can Use Shield - the shield companion

All eleven are on by default.

The table is the measured/intended support; Wall Run and Rope Swing were not played on ALS.

What the hero is doing: the action list

Get Corridor Action returns one value per frame. When several are true the highest wins:

Dead > Mount > Rail Hang > Grind Rail > Wall Run > Rope Swing > Cyclone > Spin > Slide > Slam > Crouch > Glide > Double Jump > None

On Action Started and On Action Ended fire when the value changes: the old action ends first, then the new one starts. None is not reported.
