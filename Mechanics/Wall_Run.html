Wall Run

On this page

1. What it does

Jump into a placed wall run and the hero runs along the wall (900 cm/s), slowing near the end, and can leap off at an angle. The wall run is a level actor: you draw where it goes.

2. Turn on / off

  • Details: Corridor | Abilities > Can Wall Run.
  • Blueprint: Set Ability Enabled (Ability = Wall Run) / Is Ability Enabled.
  • Routes: A only with the kit's movement component or the ALS sample (on a plain Character Movement the wall is scenery, whatever the switch says) - B yes - C yes (same code path as the grind rail; not played on ALS).
  • Switched off during a run: the hero drops off the wall. Switched off before: the wall is just a wall; it keeps its collision, so the hero stands and slides against it.

3. Level actor to place

Corridor Wall Run (Place Actors > search "Wall Run"; class ACorridorWallRun). Edit its Path spline along the wall face at the hero's middle height. Set Right Wall first if the wall is on the hero's right. The wall mesh on the actor is a simple stand-in: put your own wall behind the spline.

4. Details fields

On the Corridor Wall Run actor (Corridor | WallRun):

Field Default What it does
Right Wall (bRightWall) false The wall is on the hero's right; off = on its left. (Details: Corridor | WallRun)
Run Speed (RunSpeed) 900 Speed along the wall (cm/s): a run a little quicker than the 643 ground run. (Details: Corridor | WallRun)
Begin Falling Distance (BeginFallingDistance) 289 The last stretch of the wall (cm) where the run slows to FinalSpeed and the hero starts to drop. (Details: Corridor | WallRun)
Final Speed (FinalSpeed) 257 Run speed at the very end of the wall (cm/s); it also carries the hero off the end. (Details: Corridor | WallRun)
Drop Distance (DropDistance) 26 How far the hero sinks over the last stretch before it falls (cm). (Details: Corridor | WallRun)
Can Jump Off Delay (CanJumpOffDelay) 0.25 Jumping is ignored for this long after the hero caught the wall (s). (Details: Corridor | WallRun)
Leap Pitch (LeapPitch) 30 The leap arrow: degrees up and degrees off the wall. (Details: Corridor | WallRun)
Leap Yaw (LeapYaw) 65 Degrees off the wall the leap arrow points. (Details: Corridor | WallRun)
Leap Speed (LeapSpeed) 1286 Speed of the leap along the arrow (cm/s), added on top of the run's own speed. (Details: Corridor | WallRun)
Leap Multiplier (LeapMultiplier) 1 Scales LeapSpeed for this wall (1 = as is); below 1 a shorter leap, above 1 a longer one. (Details: Corridor | WallRun)
Capture Distance (CaptureDistance) 120 How close (beside the line) the hero catches it. (Details: Corridor | WallRun)
Theme Art (bThemeArt) false Theme art draws this wall: with a theme in a game world the stand-in wall hides (its collision stays). (Details: Corridor | Theme)

On the hero (Corridor | Traversal): Wall Leap No Brake Time, Wall Leap No Control Time, Wall Leap Air Control Scale, Traversal Fx.

5. Blueprint functions and events

The wall run actor itself has no nodes: read the state on the hero.

Node Kind What it does
Set Ability Enabled / Is Ability Enabled Function / Getter The switch above (Ability = Wall Run).
Get Corridor Action Getter Wall Run while running along the wall.
On Action Started / Ended Event dispatchers Started when the hero attaches; Ended on the leap, the end of the wall or death.
Is Wall On Right (movement component) Getter True if the wall is on the hero's right: mirror your pose otherwise.
Is Wall Run Ending (movement component) Getter True near the end of the wall while the hero falls off it.
Get Traversal Age (movement component) Getter Seconds since the wall run started.
Get Traversal (movement component) Getter Which traversal is active (Grind, WallRun, Rope).

6. Use your own animation

Leave Anim Set empty. In your Anim Blueprint switch on Get Corridor Action = Wall Run, blend your pose with Is Wall On Right (mirror) and Is Wall Run Ending. Sounds on On Action Started / Ended. A Slot node is only needed when you use the kit's clips.

7. See it in the demo

Course4_RideChase: the wall runs after the first rail section. Stand at the foot of a wall and jump into it.

8. Pitfalls

  • The wall run only watches the first player (no AI, no second player).
  • A hero that must wall-run to cross a pit cannot cross it with Wall Run off.
  • The hero catches the wall by touching it in the air; Capture Distance is how near it must be.
