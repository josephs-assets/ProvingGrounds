Mechanics Reference

One page per mechanic, all with the same eight headings so you can skim: what it does, turn on / off, level actor to place, Details fields, Blueprint functions and events, use your own animation, see it in the demo, pitfalls. Details defaults are read from the plugin, so they match the tooltips in the editor.

Every mechanic that is a hero move has one checkbox under Corridor | Abilities and can be switched at run time with Set Ability Enabled. What the hero is doing right now is one node, Get Corridor Action, plus the events On Action Started and On Action Ended: that is what your own Anim Blueprint reads.
