Rope Swing

On this page

  • 2. Turn on / off
  • 3. Level actor to place

  • 5. Blueprint functions and events
  • 6. Use your own animation

1. What it does

A rope swings from a hang point. The hero grabs it, climbs, slides down and leaps off with the rope's momentum (x1.25 plus a lift).

2. Turn on / off

  • Details: Corridor | Abilities > Can Rope Swing.
  • Blueprint: Set Ability Enabled (Ability = Rope Swing) / Is Ability Enabled.
  • Routes: A only with the kit's movement component or ALS - B yes - C yes (not played on ALS).
  • Switched off on the rope: the hero lets go. Switched off before: the rope is scenery that keeps swinging.

3. Level actor to place

Corridor Rope Swing (ACorridorRopeSwing). The actor's location is the hang point; it swings about its right axis. Set Length first.

4. Details fields

Field Default What it does
Length (Length) 1131 Length of the rope (cm). (Details: Corridor | Rope)
Swing Angle (SwingAngle) 30 How far the rope swings to each side of straight down (degrees). (Details: Corridor | Rope)
Seconds Per Swing (SecondsPerSwing) 3 Time of one swing (s). (Details: Corridor | Rope)
Start Phase (StartPhase) 0.25 Where in the swing cycle the rope starts, 0..1. (Details: Corridor | Rope)
Grab From (GrabFrom) 0.59 The grabbable part of the rope: from this share of its length to the end (0..1). (Details: Corridor | Rope)
Grab Radius (GrabRadius) 90 How close the hero's hands must come to the rope to grab it (cm). (Details: Corridor | Rope)
Leap Multiplier (LeapMultiplier) 1.25 The leap: the rope's speed there x this... (Details: Corridor | Rope)
Leap Up (LeapUp) 900 ...plus this upward speed (cm/s). (Details: Corridor | Rope)
Climb Speed (ClimbSpeed) 257 Speed climbing up the rope with the stick (cm/s). (Details: Corridor | Rope)
Slide Speed (SlideSpeed) 514 Speed sliding down the rope with the stick (cm/s). (Details: Corridor | Rope)
Stick Delay (StickDelay) 0.5 No climbing right after the grab (s). (Details: Corridor | Rope)

5. Blueprint functions and events

Node Kind What it does
Set Ability Enabled / Is Ability Enabled Function / Getter The switch above (Ability = Rope Swing).
Get Corridor Action Getter Rope Swing while hanging, climbing or sliding down.
On Action Started / Ended Event dispatchers Started at the grab, Ended at the leap or death.
Get Rope Climb (movement component) Getter How far the hero has climbed (cm along the rope): drives a climb blend.
Get Rope Sway (movement component) Getter The swing now: drives a sway blend.
Get Traversal Age (movement component) Getter Seconds since the grab.

6. Use your own animation

Leave Anim Set empty; Get Corridor Action = Rope Swing; blend Climb with Get Rope Climb and Sway with Get Rope Sway.

7. See it in the demo

Course4_RideChase: the ropes between the rail sections. Jump toward the rope's hanging end.

8. Pitfalls

  • Only the first player can grab a rope.
  • The rope leap speed is the rope's own speed x1.25 plus the lift: a rope barely swinging gives a short leap.
  • A rope as the only way over a pit blocks the level when Rope Swing is off.
