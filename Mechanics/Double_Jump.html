Double Jump

On this page
  • 1. What it does
  • 2. Turn on / off
  • 3. Level actor to place

  • 5. Blueprint functions and events

1. What it does

Press Jump again in mid-air for a second, higher jump (+211 cm on the kit hero). The ground jump, coyote time, the jump buffer and the crate bounce are not part of this switch: they always work, because the character has to be able to move.

2. Turn on / off

  • Details: select your character Blueprint, open Class Defaults, find Corridor | Abilities > Can Double Jump (on by default).
  • Blueprint: Set Ability Enabled (Ability = Double Jump, Enabled) and Is Ability Enabled.
  • Routes: A yes (on the Corridor Hero component: 5. Abilities > Can Double Jump, honoured by Move Jump) - B yes - C yes.
  • Switched off in mid-air: the next press does nothing (the press is still buffered, so it becomes a normal ground jump on landing). The Cyclone power keeps its own two-jump even with Double Jump off, so "only power-ups" setups still feel right.

3. Level actor to place

None. It is pure movement.

4. Details fields

Jump feel on the Corridor Character (Corridor | Jump):

Field Default What it does
Jump Velocity (JumpVelocity) 1157 Initial jump speed (cm/s); kept constant while the button is held (up to JumpMaxHold). (Details: Corridor | Jump)
Jump Max Hold (JumpMaxHold) 0.12 How long holding jump keeps the upward speed constant. (Details: Corridor | Jump)
Double Jump Velocity (DoubleJumpVelocity) 1872 Second jump speed (cm/s); not affected by holding. (Details: Corridor | Jump)
Double Jump Horizontal Keep (DoubleJumpHorizontalKeep) 0 Share of horizontal speed kept by the double jump (0 = the double jump stops sideways movement). (Details: Corridor | Jump)
Double Jump Air Accel Scale (DoubleJumpAirAccelScale) 0.5 Air acceleration multiplier after a double jump until landing. (Details: Corridor | Jump)
Near Ground Share (NearGroundShare) 0.1 A press with walkable ground this close below (share of the probe) is kept for landing, not spent on the double jump. (Details: Corridor | Jump)
Coyote Time (CoyoteTime) 0.1 Grace period after walking off a ledge in which a ground jump is still allowed. (Details: Corridor | Jump)
Jump Buffer Time (JumpBufferTime) 0.1 A jump pressed this long before landing still fires on landing. (Details: Corridor | Jump)
Near Miss (bNearMiss) true The near miss: falling against a ledge whose top is just out of reach stops the hero at its face, turns them to it and plays the NearMiss event (sound, rumble) and the anim set's NearMiss clip; then the fall goes on. Off = they slide down the face. (Details: Corridor | Jump)

On your own character (Corridor Hero component, 4. Moves):

Field Default What it does
Double Jump Height (DoubleJumpHeight) 211 Height the double jump climbs above the press point (the kit hero's: 211 cm), at your character's own gravity. (Details: 4. Moves)

5. Blueprint functions and events

Node Kind What it does
Set Ability Enabled / Is Ability Enabled Function / Getter The switch above (Ability = Double Jump).
Get Corridor Action Getter Returns Double Jump while the hero rises from the second jump, until the apex.
On Action Started / On Action Ended Event dispatchers Fire with Double Jump at the start and at the apex or landing.
On Corridor Jump Event Fires on every jump with a "double jump" flag. It also fires for wall and rope leaps.
Get Double Jump Count Getter How many double jumps since the last landing.
Move Jump Function Option A: call it from your Jump input before your own jump; it returns false in the air when Double Jump is off.

6. Use your own animation

An empty character Anim Set falls back to the active theme's Anim Set (both shipped themes use DA_HeroActions), and with Animation Mode External its double-jump clip plays on Action Slot. For your own clip only, duplicate your theme, clear the copy's Hero > Anim Set and select the copy on the level's BP_Control > 3 Theme, with the character's own Anim Set (Class Defaults > Corridor | Animation) left empty. In your Anim Blueprint read Get Corridor Action and switch on Double Jump; use On Action Started for the sound. Locomotion comes back by itself when the action ends.

7. See it in the demo

Course1_RunAndJump: stand at the first wide gap and press Jump twice. System_Gallery has the same gap rows.

8. Pitfalls

  • A crate bounce counts as the double jump already used; an enemy bounce keeps it, so you can chain a stomp into a double jump.
  • A wall, rope or rail resets it, so the hero can double jump after every leap. That is intended.
  • With Double Jump on, a press in the air double-jumps first and only then can hold into a glide.
