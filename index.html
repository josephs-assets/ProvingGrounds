Proving Grounds: 3D Platformer Mechanics - documentation index

Product name used in the docs: Proving Grounds: 3D Platformer Mechanics (the name is set in this file, README.md and the plugin readme only).

Start with the Quickstart. You use the Content Browser, the Details panel and Blueprint nodes: no code is needed anywhere.

Pick your route

Option A keeps your character and adds crates, enemies and checkpoints. Option B reparents it to Corridor Character for the full move set. Option C is the ALS-Refactored sample. Details: Option A, B or C.

Support: found a problem or have a question? Open an issue and include your Unreal Engine version, the mechanic, and any LogTemp or Corridor lines from the Output Log.
