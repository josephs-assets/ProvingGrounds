1. Overview

This kit is a complete 3D platformer as a code plugin (PlatformerKit, with all its content). You build levels by placing actors and editing their Details-panel properties; you extend the game with Blueprints. You write no C++ for either.

In the box

  • Hero (ACorridorCharacter): variable-height jump, double jump, coyote time, jump buffer, spin attack, slide, crouch/crawl, belly flop, crate bounces, ice, dark-matter and flipped-gravity movement, rails, wall runs, rope swings, mounts.
  • 16 crate types (ACorridorCrate): basic, bounce, arrow, metal, fuse box, volatile box, checkpoint, "?", strong, "!" switches, shield crate, big orb, time crate, N-bounce crate. Stacks fall when their support breaks.
  • 10 enemy kinds (ACorridorEnemy): walkers, spiked, shooter, spitter, crab, charger, flyer, armored, kamikaze. Spin one and it becomes a projectile.
  • Hazards, platforms and traversal: spinning, swinging, crushing, dropping, rolling and timed hazards; moving, sinking, breakable, rotating and bonus platforms; bounce pads, push fans, ice; grind rails with obstacles, wall runs, rope swings; a chase wall; ridden mounts with ramps.
  • 5 powers (phase, cyclone, time slow, gravity, glide) and the shield that absorbs hits.
  • Progress: loot counter, crate/deaths/orbs/hidden/coloured gems, a deathless pickup, a perfect run, skins with unlock rules, pause menu, level end screen, a level table with unlock rules, a level select menu, saved best results.
  • Modes: Casual and Classic difficulty, time trial with medals and ghost, mirror mode.
  • Boss framework: a director that runs phases, a tile-grid arena, attack loops and final attacks, health bar, scenes. Two example boss maps.
  • Cameras: rail, side, chase and fixed views switched by boxes, a crossfader, and camera fade for what blocks the view.
  • Theme data asset (UCorridorTheme) that swaps looks, animations, sounds, effects, HUD icons and music without touching the maps.
  • Automated test runner (-CrateTest, -JumpTest).

Look and sound. The demos use the project's own Lab theme with original models and an original sound library. Replace looks and sounds through a theme asset (section 9, SOUND.md) or the placed actors' Details panels.

Technical. DirectX 12 / SM6, Lumen GI and reflections, virtual shadow maps, static lighting off (see "Project render settings" in the Quickstart). Input is Enhanced Input (/PlatformerKit/Input). All menus and screens are UMG widgets built in code; each can be replaced by a Blueprint child.

2. Quick start

Install the plugin

Requirements: Unreal Engine 5.3–5.8, Windows. A Blueprint-only project needs nothing else to play in the editor; packaging needs Visual Studio 2022 (see "Packaging").

  1. Add the product to your library on Fab, then in the Epic Games Launcher > Library > Fab Library press Install to Engine and pick your engine version (5.3–5.8). (To install by hand, copy the plugin folder into your project's Plugins folder.)
  2. Open your project. If Unreal asks to enable the plugin or rebuild, accept. Otherwise open Edit > Plugins, search for PlatformerKit, tick Enabled and Restart Now. The plugin enables the engine plugins it needs (Enhanced Input, ACL, Control Rig, RigVM, Full Body IK, Animation Data).
  3. In the Content Browser open Settings and tick Plugin Content (5.3–5.5: Show Plugin Content). The kit's assets are in the plugin folder Proving Grounds: 3D Platformer Mechanics (folder PlatformerKit).
  4. Open Proving Grounds: 3D Platformer Mechanics > Maps > Corridor_Menu and press Play. Every map sets its own game mode, so you do not change Maps & Modes, and the demo does not touch your project's game mode or input settings. Pick a level with the mouse or the gamepad stick; all of them are open.
  5. Optional: set Project Settings > Maps & Modes > Game Default Map to Corridor_Menu so a packaged game starts at the menu.

Put your own assets in your own Content folder, never inside the plugin folder, so updating the plugin never overwrites your work.

Project render settings

The demo maps are lit for Lumen. A project made from the UE 5.5–5.8 Third Person, Blank or another template at the default Maximum quality already has all of these (a 5.3 or 5.4 template project has all but Allow Static Lighting: set it Off). A project upgraded from UE4, or made with the Scalable preset, may not. Check Project Settings > Engine > Rendering:

Setting Value Needs editor restart
Global Illumination > Dynamic Global Illumination Method Lumen no
Reflections > Reflection Method Lumen no
Shadows > Shadow Map Method Virtual Shadow Maps yes
Software Ray Tracing > Generate Mesh Distance Fields On yes
Default Settings > Allow Static Lighting Off yes

Without them the maps still load and play with no errors, but Unreal then lights them without Lumen (no dynamic global illumination, screen-space reflections), so the look differs from the listing images. Nothing else is needed: no input mappings, no collision channels or profiles, no console variables.

Find and customize the Blueprint actors

Open Proving Grounds: 3D Platformer Mechanics > Blueprints. Gameplay actors in the original demos are Blueprint children; select one in the level and press Ctrl+B to locate its asset. Place one Core/BP_Control for difficulty, camera, theme, HUD and testing settings. The plugin's assets appear under Proving Grounds: 3D Platformer Mechanics (Content Browser > Settings > Plugin Content).

Change the hero: duplicate the active theme, create or duplicate a CorridorAnimSet, set its Mesh and compatible clips, assign it to the new theme, then select that theme in BP_Control > 3 Theme and restart Play. Follow BUYER_QUICKSTART.md for the complete path and a compatible-mesh example.

Controls

The keys live in the mapping context /PlatformerKit/Input/IMC_Corridor (actions IA_MoveForward, IA_MoveRight, IA_Jump, IA_Spin, IA_Slide, IA_Power, IA_LookRight, IA_LookUp, IA_Pause): open it to rebind. The hero's Input category in Details points at these assets; if one is cleared or missing the hero falls back to the built-in default keys below.

Action Keyboard / mouse Gamepad
Move (along the camera) W A S D Left stick
Jump (hold = higher, press again in the air = double jump) Space Bottom face button (A)
Spin attack J, Left mouse button Left face button (X)
Slide / crouch / belly flop K, Left Shift Right face button (B)
Power on / off Q, Right mouse button Top face button (Y), Right trigger
Pan the camera a little Arrow keys Right stick
Pause menu Escape, P (in the editor's Play: P, Escape stops the session) Start / Options
Console (live tuning) F10 -
  • The moves have a page each, with every Details field and Blueprint node: Double Jump (jump buffer, coyote time, near miss), Spin (mash chain, triple spin), Slide and Crouch, Slam and Crates, bounce and ground jump. In short: Slide is slide with the stick pushed, crouch with it released, belly flop (slam) in the air; Jump during a slide or crouch gives the higher slide jump.
  • While riding a mount the stick, jump and spin are the mount's (spin = boost).
  • Console commands on the hero: JumpScale, RunSpeed, CamDist, CamPitch, CamFov, Tuning (prints the current values).
  • For touch UI or your own input, call the hero's OnJumpPressed, OnJumpReleased, OnSpinPressed, OnSlidePressed, OnSlideReleased, OnPowerPressed, OnPausePressed and AddStickInput from Blueprint.
  • The pause menu (UCorridorPauseWidget, opened by ACorridorHUD::TogglePause) stops the game and shows the level's crates, orbs and deaths so far, with "Resume", "Restart Level" and "Return to Map". The pause key or the gamepad's B / Circle closes it. It does not open over the level end or game over screen.

4. Building a level

Conventions

  • Scale: the hero is 180 cm tall (capsule 35 radius x 90 half height), runs at 643 cm/s, a crate is 77 cm. Lengths in the properties are centimetres, times are seconds.
  • A crate's origin is its bottom centre: put it on the floor at Z = 0 and it sits on the floor.
  • The default camera looks along +X (ACorridorCharacter.CameraYaw = 0): W runs toward +X. Distance 650, pitch -22, field of view 90. A camera view actor overrides it inside its box.
  • Falling below KillZ (-1000) kills the hero. For water or pits you can see into, place a ACorridorKillBox.

Minimum level

  1. New level from any template. Floor, a PlayerStart. The hero spawns there and that spot is the first respawn point.
  2. Set World Settings > GameMode Override to BP_GameMode (Proving Grounds: 3D Platformer Mechanics > Blueprints > Core). The kit never changes your project's default game mode, so without the override a new level spawns your project's own character. (To change HUD or hero defaults make Blueprint children of ACorridorGameMode, ACorridorCharacter, ACorridorHUD and use the game mode child as override.)
  3. Place crates, enemies and so on from the table below. Add checkpoints, then an ACorridorLevelEnd.
  4. Add a row for the map in the level table if it should appear in the menu (section 5).

At play start the game mode counts the level's crates, orbs and hidden gems itself: nothing to enter by hand.

The level control - ACorridorControl

One per level, anywhere (an editor-only sprite marks it): the single place for the level's daily settings. At play it hands its values to the game mode, the hero and the HUD; a level without one uses their own settings, exactly as before. From Blueprint: Get (the level's control, or none) and Apply (hands the values over again after a change at run time; a rule change mid-level starts a fresh count of StartLives).

Category Settings
1 Difficulty Rule Casual / Classic, StartLives, MaxLives (game mode Difficulty, StartLives, MaxLives).
2 Camera CameraDistance, CameraPitch, FieldOfView of the default camera (hero SetDefaultCamera); camera views whose own FieldOfView is 0 use the same lens.
3 Theme Theme: this level's look and sound. Empty falls back to the project Default Theme; development overrides are explained in section 9. Restart Play after changing the hero mesh or animation set.
4 HUD Counters Auto Hide / Always Shown, HideAfter, bShowOrbs, bShowCrates, bShowLives (HUD bAlwaysShowCounters, TimeBeforeHide, bShowLoot, bShowCrates, bShowLives).
5 Testing bUnlockAllLevels (put the control in the menu level: every level select row is open), bImmortal (hazard and enemy hits do nothing; falling out still respawns). Both off by default: leave them off for a release.

Crates - ACorridorCrate

One actor, Type picks the behaviour.

Type Behaviour
Basic Breaks on landing, spin or head-bump; gives LootOnBreak orbs; bounces the hero.
Bounce Bounces the hero and gives LootPerBounce orbs each time; breaks after BounceLootHits.
Arrow / MetalArrow High bounce (ArrowBounceHeld / ArrowBounceUnheld); the arrow breaks only by spin or explosion, the metal one never.
Metal Plain bounce, unbreakable.
Fuse Landing lights a FuseTime fuse; spin or explosion sets it off at once.
Volatile Any touch detonates it; hops at random times (VolatileHopInterval).
Checkpoint Breaking it moves the respawn point; CheckpointLoot orbs, CheckpointPower = power worn after respawn.
Surprise Like Basic, SurpriseLoot (7-12) orbs.
Strong Bounces the hero; opened only by a belly flop or an explosion.
Switch Metal "!": makes outline crates real (all of them, or only SwitchTargets, which can also start moving and rotating platforms).
Detonator Green "!": sets off every volatile box in the level.
Shield Gives the shield companion (section 7).
BigOrb One big orb worth BigOrbLoot; in Classic mode a life instead.
Time Time trial only: no orbs, stops the clock TimePause seconds.
NBounce Metal: bounces the hero NBounces times (1-9, the number on it counts down), then turns into a volatile box (set it off with a Detonator for the crate count); a death brings it back.

Also: bOutline (see-through, no collision until a "!" crate makes it real; OutlineCountdown turns it back), Size, ExplosionExtent, ChainDelay, StackFallTime. Metal, MetalArrow, Switch and Detonator crates do not count toward the crate gem. Blueprint events: OnBroken(bByExplosion), OnExploded.

Enemies - ACorridorEnemy

Set Kind first: changing Kind (or Cargo) loads that kind's defaults into Speed, TurnTime and bWaitForHero. Draw the patrol on the Path spline (local, along the floor; one point = stands still; a flyer flies it as drawn). SenseBox wakes it when the hero enters.

Kind Behaviour
Plain Walks its path: stomp, spin, slide or belly flop kills it; touching it from the side kills you.
SideSpikes Spiked sides: kill it from above only.
TopSpikes Spiked top: only spin or slide.
Shooter Stands, turns to you in range and throws.
Spitter Spits a poison glob that pools; hides when you come close.
Crab Waits, then walks sideways along its path.
Charger Waits, winds up (ChargeWindup), runs its path fast.
Flyer Flies a 3D path; Cargo None / Orbs / Crate (CargoCrate dropped when the hero passes under).
Armored Spiked shield: Shield Forward, Up or Alternating (ShieldSwitchTime).
Kamikaze Runs to the end and explodes; only a thrown enemy or crate kills it.

A spun or slid enemy becomes a projectile (LaunchSpeed, LaunchTime) that breaks crates and other enemies; with LaunchTarget set it flies to that actor (this is how bosses are hit, section 8). An enemy killed before a checkpoint stays dead; after it, it returns when the hero respawns.

Hazards, pits, ice, fans

Actor Use
ACorridorHazard Mesh (the look, swap freely) + KillZone (size it to the dangerous part). Death picks the death kind, Motion: None, Spin, Swing, Crush, Drop, Roll (back and forth RollDistance along X every RollPeriod, the mesh turning as a wheel of RollRadius; the kill zone does not turn). bTimed adds the tell / active / off cycle (TellTime, ActiveTime, OffTime; StartOffset staggers a row). bIgnoreShield makes the shield not absorb it.
ACorridorKillBox Pit or water volume; Death (default Fall).
ACorridorSlipperyVolume Ice inside the box (hero values: IceFriction, IceAccelerationScale, IceAirControl...).
ACorridorBouncePad BounceVelocity (1286), HeldBounceVelocity (1800) with jump held.
ACorridorPushFan Updraft column (LiftSpeed, Radius, Height); tilt it for a sideways fan; SetOn.
ACorridorWater Water for jetboards: size Box, its top face is the surface (Surface is the look). Touching it on foot or on another mount kills (Death, default Water; bKillsOnFoot). Several can sit at different heights: a board floats on the highest one under it.
ACorridorWhirlpool Jetboard hazard on the water: pulls a ridden board round and in within Radius (EdgePull almost sideways at the rim, CenterPull straight in at CenterRadius), drowns the rider within KillRadius.

Death kinds (ECorridorDeath): Touch, Fall, Explosion, Squash, Water, Drown, Poison, Electric, Burn, Lava, Ice, Knockback, FallDrop, volatile box, RailHigh, RailLow, RailHang, Bite. Each has its own timing and effect. On most the camera stops and the hero leaves the frame; Bite (set it as a chaser's Death for a monster that catches the hero) is a caught death: the camera moves in on the hero (CaughtPushIn 193 cm over CaughtPushTime 0.5 s on the hero's camera director) and the respawn waits 2 s more. In your own Blueprint hazards call the hero's TakeHit(How, bIgnoreShield); use Die only to kill regardless of the shield.

Platforms

All derive from ACorridorPlatform (swappable Mesh, bResetOnRespawn, warning shake).

Actor Use
ACorridorMovingPlatform Draw the Path spline. StartOn: OnStep, OnTrigger (call Trigger()), Always. Route: StepToReturn, OneWay, PingPong, Loop. Speed 257, bBreakOnAttack.
ACorridorPlatformTrigger Box that starts the platforms listed in Targets when the hero walks in.
ACorridorSinkingPlatform Dips, sinks SinkDepth, stays down DownTime, rises.
ACorridorBreakablePlatform Cracks BreakDelay after landing, returns after RespawnTime.
ACorridorRotatingPlatform Holds HoldTime, turns RotationAmount (90) about Axis (Roll, Pitch, Yaw) eased over TurnTime, holds, turns back (bKeepTurning: on the same way). CycleOffset staggers a row, a TellTime shake comes before each turn, StartOn as on the moving platform. Tipped past the walkable slope, the hero slides off.
ACorridorBonusPlatform Carries the hero along Path in Duration. Place two at the same spot: the way in (starts the bonus rule: deaths there do not count) and the way back (bReturnTrip, optionally TeleportTo with a fade). A bonus room somewhere else: the way in's TeleportTo is another bonus platform with bReturnTrip - you come out on it and it carries you in (it can wait out of sight: under the floor, behind the play line); the same at the room's exit, back to the path. CameraView switches the view as a platform takes you on. RequiredGem turns it into a gem platform.

Traversal, chase, mounts

Each has its own page in the Mechanics Reference.

Actor Page
ACorridorGrindRail, ACorridorRailObstacle Grind Rail
ACorridorWallRun Wall Run
ACorridorRopeSwing Rope Swing
ACorridorMount, ACorridorJetboard, ACorridorMountRamp, ACorridorMountStatGate Mounts and Jetboard
ACorridorChaser Kill wall running along Path behind the hero, rubber-banded by distance. StartBox starts it; Body is the monster's look. Its steps (StepInterval 0.45 s, quicker with its rate) shake the camera by distance (StepShake 5 cm up, StepShakeTime, StepShakeRange) and play the ChaseStep event (sound + rumble). Checkpoints, orbs, gems, hints, level end

Actor Use
ACorridorCheckpointTrigger Invisible checkpoint; ForcedPower = power worn after respawn. (The Checkpoint crate does the same.)
ACorridorLoot An orbs; flies to the HUD counter, where the icon pops and a burst of rays and sparkles flies out (ACorridorHUD::LootBurstTime 0.467 s, LootBurstColor; 0 = none).
ACorridorGem Color Clear = the level's hidden gem; Red / Green / Blue / Yellow / Purple = coloured gem kept across levels.
ACorridorDeathlessPickup Can be taken only while the run has no deaths (a bonus path death does not count). After a death it turns see-through (GhostMaterial) and can't be taken: restart the level to try again. Taken = saved at once in the level's results (bDeathlessPickup); once owned it is see-through on later runs. Place it late in the level, one per level.
ACorridorHintTrigger Shows Hint on the HUD for Duration (2.5 s).
ACorridorLevelEnd Finishes the level (FinishLevel): results, gems, level end screen. Its end scene (bEndScene, on by default) cuts the view to the hero's front and moves in (EndViewStart → EndViewZoom over EndViewTime, 1.25 s) while the hero plays its anim set's Celebrate; the level end screen sits on the right so the hero stays in view.
ACorridorPowerShrine, ACorridorPowerRemover Give / take a power (section 7).

On a death the hero returns to the last checkpoint; the screen goes black just as it respawns and comes back after (DeathFadeOut 0.5 s, DeathFadeIn 0.6 s, DeathFadeColor; 0 = no fade, none on the Classic game over). Crates broken and enemies killed since then come back, and so does the orbs taken since then in Casual mode; in Classic mode taken orbs stays taken.

Cameras - ACorridorCameraView

The hero walking into one of its boxes (Volume, plus any box you add) makes it the active view, blended over BlendInTime. Mode: Rail (rides the Rail spline above the path), PlayerOffset (hero + world offset), Fixed (the actor's own transform), Behind (behind the hero's facing, swinging round with it at BehindYawSpeed). Preset fills the numbers: Corridor (behind the hero), Side (2D beside the rail), Chase (in front), Follow, Vehicle (behind a jetboard), Custom. ACorridorCameraCrossfader mixes two views along a short spline. With no view the hero's default camera is used.

FieldOfView (degrees, blended in with the switch; 0 = the hero's camera director DefaultFieldOfView, 90) gives a view its own lens: narrow for a boss arena, wide for a vista.

Camera fade. Something that blocks the camera's view of the hero from one spot (a swinging hazard, a pillar, an enemy on a ledge): place an ACorridorCameraFadeVolume where the hero stands at that moment and pick the blocking actors in its FadeableActors; they may stand outside the box. While the hero is inside they fade out (dithered, collision stays) and come back when the hero leaves. Each actor's UCorridorCameraFadeComponent (added with the defaults if missing) holds FadeOutTime / FadeInTime, FadedAlpha (0 = gone, 0.25-0.35 = a ghost) and CameraDistance (fade on its own while the camera is that close, no volume needed). The smooth fade needs a Masked material with Dither Opacity Mask on and the scalar parameter CameraFade in its Opacity Mask (MF_CorridorCameraFade is that parameter), or map your material to such a version in ReplacementMaterials. The shipped shape, crate, hazard and mannequin materials already have theirs (/PlatformerKit/Corridor/Materials/CameraFade); M_PlasterWall (a door-wall material) fades as it is. A mesh with neither - the prototype grid included - is hidden halfway through the fade instead.

5. Level table and progression

DT_CorridorLevels is a Data Table with row struct FCorridorLevelRow. It feeds the level select, the unlock rules, "Continue" and the time trial medals.

Field Meaning
Row name The level id. Results are saved under it. It must equal the map's short name (for example Course1_RunAndJump), or set LevelId on the level's game mode.
DisplayName Name in the menu (empty: the row name).
Map The map this row opens (soft reference).
UnlockAfter Row names whose finish opens this level; empty = open from the start.
UnlockCount How many of UnlockAfter must be finished; 0 = all.
BronzeTime, SilverTime, GoldTime, MasterTime Time trial medal limits in seconds; 0 = no such medal.

The shipped table has the menu's seven entries (Course 1 to 4, Boss 1, Boss 2, System Gallery); all of them are open from the start. Unlock rules are an optional feature for the game you build.

Adding a level: make the map, add a row (same name as the map), set Map, set the unlock rule. A level that is not in the table is always open and has no medals.

Where the table is read: ACorridorGameMode.LevelTable, MenuMap and SkinTable come from the plugin's Config/Game.ini, section [/Script/PlatformerKit.CorridorGameMode]. The menu actor has its own LevelTable and SkinTable properties, set them to the same assets.

Level select (ACorridorLevelSelect, in Corridor_Menu): a list of the table rows with saved gems ("n / 6"), "done", "deathless" and "perfect"; locked levels are greyed. Beside it a card shows the focused or hovered level: six gem badges, deathless pickup, perfect run, best deaths / orbs / crates, time trial best and medal, mirrored gems, or what unlocks it (ShowCard, CardLevel). WidgetClass accepts a Blueprint child of UCorridorLevelSelectWidget with your own design. The widget's bShowMirror shows the MIRROR toggle (section 6).

Skins (DT_CorridorSkins, rows of FCorridorSkinRow): a skin is a Mesh (same skeleton as the hero) and / or a Materials list (one per mesh slot, empty entry = the mesh's own), opened by its Unlock rule: Always, LevelGems (6 / 6 in Level), LevelComplete (Level finished), TotalGems, DeathlessPickups or PerfectRuns (Count over every saved level). ForMesh limits a skin to one hero mesh, so a theme with its own hero keeps its look. The level select's SKIN button steps through the open ones (saved at once) and names what opens the next locked one; the hero puts the saved skin on when a level starts (ApplySkin; a power's costume takes it off while worn). The demo table: Quinn (finish Test Course), Gold (10 gems), Midnight (1 deathless pickup), Crimson (1 perfect run). From Blueprints: UCorridorProgress IsSkinUnlocked, GetSkinRequirement, GetSkin, SetSkin.

Results. At the level end (FinishLevel) the game mode awards, and the save keeps the best of every run:

  • crate gem: every crate that counts was broken in one run;
  • deaths gem: Deaths no more than MaxDeathsForGem (3);
  • orb gems: 1 to 3, at OrbGemPercents (40 / 60 / 80 %) of the level's orbs;
  • hidden gems: ACorridorGem with Color Clear found in the run;
  • deathless pickup: ACorridorDeathlessPickup taken (saved the moment it is taken, not at the level end);
  • perfect run (bPerfectRun): no deaths, every crate and orbs up to the third orb gem in one run; hidden gems not needed, never in a time trial. IsPerfectRun tells a HUD whether the run still qualifies;
  • time trial: best time and medal.

The level end screen (UCorridorLevelEndWidget) shows them (plus "Deathless pickup yes / no" and "PERFECT RUN") with "Replay" and "Continue"; the six gem slots come in one by one (GemRevealTime 1.25 s, GemRevealStep 0.15 s, 0 = all at once), each earned one with the theme's GemAppear sound, then the stats line. Sounds: LevelEndAppear, LevelEndGems, LevelEndDeaths, LevelEndReward (perfect run or deathless pickup). After the end scene, Replay / Continue first sends the hero running off the screen's left (Leave, ExitRunTime 0.6 s, LevelEndContinue / LevelEndReplay + LevelEndReplayVoice) while the view holds still. Continue opens the next open row in table order, else MenuMap, else replays the level. Coloured gems are saved at once and open gem platforms (RequiredGem). Save slot: ProgressSlot ("CorridorProgress"), a UCorridorSaveGame; UCorridorProgress reads it from any Blueprint (GetLevelResult, IsLevelUnlocked, GetGemCount).

6. Game modes

Mode How it is turned on
Casual / Classic ACorridorGameMode.Difficulty (a Config property: set it in a game mode Blueprint child or in your project's Config/DefaultGame.ini under [/Script/PlatformerKit.CorridorGameMode]). Casual: endless lives, deaths counted, orbs taken since the checkpoint returns. Classic: StartLives 4, MaxLives 99, OrbPerLife 100 orbs = a life, orbs stays taken, no lives = game over screen ("TRY AGAIN" / "RETURN TO MAP").
Time trial Place an ACorridorTimeTrialClock at the level start. Touching it calls StartTimeTrial: the clock runs, deaths cost no lives, the finish keeps only time and medal. Its Rules layer removes orbs, hidden gems, the deathless pickup and big orb crates and turns "?" crates into plain ones. Tag crates TimeCrate1 / TimeCrate2 / TimeCrate3 to make them time crates that stop the clock 1 / 2 / 3 seconds; tag anything a time trial must not have NoTimeTrial. By default (bRequireFinished) the clock only exists once the level was finished. Medal times come from the level table row.
Ghost On by default in a time trial (bTimeTrialGhost). The run is recorded every SnapInterval (0.15 s); a new best time is saved in the slot <ProgressSlot>_Ghost_<level id> (<level id>_Mirror in mirror mode) and replays as a see-through copy (M_Ghost) in the next run.
Mirror The level select's MIRROR toggle (a level opened with the travel option ?Mirror), the bMirrored property, or SetMirrored(true) at run time. The picture is flipped left-right by the post-process material MirrorMaterial (default M_MirrorPP; empty = only the stick input flips). Results are saved under <level id>_Mirror. In the menu a mirrored level opens once the normal one is finished.

The five powers (Phase, Cyclone, Time Slow, Gravity, Glide) are on the Powers page (Glide has its own: Glide); the shield is on Shield. Both are Option B (Corridor Character) only.

8. Boss framework

A boss fight is data plus a few placed actors. Corridor_Boss1 and Corridor_Boss2 are complete examples: open them first.

Piece Actor Role
Director ACorridorBossDirector Runs Phases in order, keeps the health (MaxHealth, BossName), sends a death back to the last checkpoint phase, shows the health bar, finishes the level when the last phase ends (bFinishLevelOnWin). StartFight if bStartOnBeginPlay is off.
Phase FCorridorBossPhase (array element) Name; End: Hits (after HitsToEnd boss hits), Timed (Duration) or Manual (AdvancePhase / SetPhase); bShowHealth, HealthOnBegin; Sequence (a Level Sequence scene while the hero waits); Camera; bCheckpoint with PlayerStart; IntroDelayFirst / IntroDelayRetry; EnableActors.
Arena ACorridorTileGrid Size columns x rows of tiles (TileSize); tiles can be dropped (shake, hold, fall) and raised. Add an ACorridorKillBox below it.
Attackers ACorridorLaneLauncher, ACorridorMissileRain, ACorridorTileChaser Lane shots (jump, slide or dodge), missiles that land on the hero's tile, a runner that walks the tiles.
Hit point ACorridorBossTarget Where the boss takes damage: an enemy spun with this as its LaunchTarget flies here and the director loses Damage health (after DamageDelay, with bullet time). Set its Director.
Script ACorridorBossAttackLoop A phase's attacks as data (Steps). Refs: LaneLauncher, Missiles, Grid, Chaser, BossTarget, BallClass. IntroDelayFirst, IntroDelayRetry, bLoop, LoopGap.

Building a fight

  1. Build the arena: tile grid, kill box, camera view, PlayerStart.
  2. Place the attackers you want and an ACorridorBossTarget (set its Director). Place a ACorridorTileChaser with Grid, Target = the boss target and an EnemyClass.
  3. Place one ACorridorBossAttackLoop per phase. Fill Steps with FCorridorAttackStep entries: Attack, PauseAfter, EveryLoops, plus the fields that attack uses (Lane, Shot, Lanes, Tiles, Ring, Value, Width, bReverse).
  4. Place the director. Add one Phases entry per phase; list in its EnableActors the attack loop and the attackers it drives. A phase's actors start when it begins and stop when it ends or the hero dies.
  5. Make the hero hit the boss: spin the tile runner into the boss target (Hits phases end after HitsToEnd of them).

ECorridorAttack steps used by the shipped fights: LaneShot, LaneVolley, MissileAtHero, DropTiles, RaiseTiles, SpawnChaser. More steps exist; every step and its fields are listed in API.md.

Your own attackers implement UCorridorBossListener (Class Settings > Implemented Interfaces) and get OnBossPhaseBegin, OnBossPhaseEnd, OnBossHeroDied, OnBossHit. For delayed steps in Blueprint save GetToken and test IsTokenCurrent afterwards: a phase change, a death or a boss hit cancels pending steps. The director also has the events OnPhaseBegin, OnPhaseEnd, OnBossDamaged, OnFightWon, and HitBoss, AdvancePhase, SetPhase as nodes.

Phases in the shipped maps: Boss 1 runs Arrival, Warmup, Comb, QuarterFall, Horseshoe, Meltdown, Shutdown. Boss 2 runs Ignition, Sidewinder, Severance, PhaseWalk, Reroute, Redline, Shutdown.

The boss body. The visible boss (parts that move, light up and hurt) is a separate actor, ACorridorBossBody: see BOSS_BODY.md. It listens to the director and the attack loops, so any fight you build here can use it.

9. Theme system

UCorridorTheme is a data asset that holds everything that gives the kit its look and sound. With no theme active the kit uses its built-in look (basic shapes, textured crate boxes, the mannequin) and the sounds in /PlatformerKit/Audio.

Create: Content Browser > Add > Miscellaneous > Data Asset > CorridorTheme.

Activate: assign the theme in the level's BP_Control > 3 Theme. To use one project-wide default, leave the level's Theme empty and select Project Settings > Game > Corridor Platformer > Default Theme.

For troubleshooting, the full priority is: command-line -Theme= override, level BP_Control Theme, development-only DevTheme, then the project Default Theme. -Theme=None forces no theme. An empty DevTheme does not disable the project default. Normal buyer setup needs neither the command line nor a config-file edit.

If an Anim Set is already assigned directly on your BP_Character child, it takes priority over the theme's Anim Set. Clear that character override when the theme should choose the hero. The built-in BP_Character leaves it empty.

The theme is loaded by path at run time: add its folder to Project Settings > Packaging > Additional Asset Directories to Cook.

Fields (all EditAnywhere):

Category Fields
Hero AnimSet (UCorridorAnimSet: the hero mesh and one clip per state; the hero's AnimSet property or -AnimSet= also takes one). Optional slots, skipped when empty: RunLeanLeft / RunLeanRight (the run leans into turns, fully at TurnLeanRate), IceIdle / IceRun / IceRunStop (on ice; the stop loop runs while it slides out), IdleFidgets (one plays after IdleTimeOut, 30 s, standing still), Teeter (standing still on an edge with a drop of TeeterHeight 50 cm under the hero's middle; IsOverLedge), NearMiss (a ledge just missed), Celebrate (level end), LeaveContinue / LeaveReplay (the run out after the level end screen)

UCorridorFx is a particle effect: a list of FCorridorFxEmitter played on the CPU with instanced meshes (no Niagara). Place an ACorridorAmbientFx (Fx, Scale) for scenery effects - torch fire, waterfall mist, dust motes: it plays from the start of play, looping emitters for good. Particles spawn at Origin, inside a sphere (SphereRadius) and/or anywhere in a box (BoxMin / BoxMax, e.g. dust over a whole room). Crate, loot, enemy and prop looks from a theme show in game worlds only; in the editor viewport the built-in stand-ins show.

Sounds.

  • No theme: an event named Jump looks for /PlatformerKit/Audio/SFX_Jump. If no matching asset exists, the event is silent. Theme keys can share clips, so the number of files is not the number of events.
  • With a theme: a sound plays only if the theme's Sounds maps the event name (a theme decides alone). Death sounds are Death_<kind> (for example Death_Fall). Power events try <Event>_<Power> (_Phase, _Cyclone, _TimeSlow, _Gravity, _Glide) first, then <Event>.
  • Animation clips can play an event with a UCorridorSfxNotify (fields Sfx, Fx, Socket). On the hero the floor's surface picks a variant first: give a floor material the physical material PM_Grass and a step plays Footstep_Grass (sound or theme effect) where that name exists, else Footstep. GetFootSurface returns the name (Grass).
  • Gamepad rumble rides on the same event names: the hero's Rumbles map (strength, duration, heavy / buzz motors; filled for blasts, deaths, impacts, breaks, bounces, pickups) rumbles whenever that event plays, with or without a sound. Death_Fall falls back to Death. Strength fades from RumbleNear (600 cm) to RumbleFar (2500 cm); the same event waits RumbleGap (0.15 s); RumbleScale 0 turns it off. Call Rumble(Event, Location) from your own Blueprints.

11. Automated tests

The kit contains an in-game test runner (ACorridorTestRunner) that was used to check the kit during development. It needs a dedicated test course that is not part of the product, so you can ignore it. To test your own levels, play them: the demo courses show every mechanic working.

12. Packaging

Standard flow: Platforms > Windows > Package Project or the Project Launcher (Win64, Development or Shipping). Set Project Settings > Maps & Modes > Game Default Map to Corridor_Menu if the game should start at the menu. Blueprint-only projects: see the Quickstart section "Packaging".

  • The plugin's Config/Game.ini always cooks the plugin's Audio, Crates, Corridor and Themes folders. Nothing references these assets directly: the code loads sounds (SFX_<Event>), crate face textures and M_Crate, the mirror, flip and ghost materials and the level table by path at run time, so a cook would otherwise leave them out. You do not need to add them.
  • Put anything else the code loads by name in those folders or add its folder under Project Settings > Packaging > Additional Asset Directories to Cook: extra SFX_ clips, your theme asset and its content.
  • List your maps under Project Settings > Packaging > List of maps to include in a packaged build. The level select opens maps by soft reference from the level table, so every map in the table must be cooked.
  • Blueprint-only projects need Visual Studio 2022 with the C++ workload for the first package: see the Quickstart section "Packaging".
  • After packaging, run the game, check the menu, one level with the sound on, a death, and the level end screen.

13. Known limitations

  • Sound events that have no SFX_<Event> clip stay silent. With a theme active, events the theme does not map are silent too. Optional voice slots remain unfilled; see section 9 for the event lookup rules.
  • The demo look is the project's own Lab theme. Real art for your game comes from your meshes or a theme (section 9).
  • Menus and result screens use a plain built-in layout; for another design make Blueprint children of UCorridorLevelSelectWidget, UCorridorLevelEndWidget, UCorridorGameOverWidget, UCorridorPauseWidget, UCorridorBossHealthWidget and set WidgetClass, LevelEndWidgetClass, GameOverWidgetClass, PauseWidgetClass, HealthWidgetClass.
  • The level select, the time trial ghost and the test runner address local player 0. No split-screen or multiplayer setup is included.
  • A level's results are saved under its level id: the row name in the level table must match the map name (or LevelId on the game mode), otherwise results are saved under the map name and the menu will not show them.
  • The time trial clock is only present once the level was finished (bRequireFinished); a mirrored level opens in the menu only after the normal one is finished.
  • A theme and anything loaded by name must be in a cooked folder (section 12).
