# Proving Grounds: 3D Platformer Mechanics

Documentation and support for **Proving Grounds: 3D Platformer Mechanics**, an Unreal Engine 5.7 code plugin by Joseph's on Fab: crates, powers, grind rails, wall runs, ropes, mounts, enemies and a camera director, all set in the Details panel and Blueprints.

- **Documentation:** https://josephs-assets.github.io/ProvingGrounds/
- **Support:** [open an issue](https://github.com/josephs-assets/ProvingGrounds/issues) - include your engine version, the mechanic, and any Corridor lines from the Output Log.

This repository holds the documentation only; the plugin is sold on Fab.
