Recipe 2: Only power-ups

Goal: the hero runs and jumps; the only special things are the powers. Route: B (powers need the Corridor Character).

Steps

  1. Reparent to Corridor Character, set the three Integration modes to External (as in Recipe 1).
  2. Class Defaults > Corridor | Abilities: untick everything except Can Use Powers (and Can Glide if you want the Glide power).
  3. Place a Corridor Power Shrine and pick its Power.
  4. Bind a key to On Power Pressed in your input graph (or use the default Q / Y).

You should see

  • The shrine appears when the hero comes within 1157 cm (its Appear Radius) and the power flies onto the back.
  • The double jump, spin attack, slide and slam do nothing. The ground jump still works.
  • Cyclone still spins and double-hops: those are its own. Glide caps the fall at 220 cm/s.

If it does not work

  • Can Use Powers is off: shrines stay hidden and Equip does nothing.
  • The character is not a Corridor Character (route A): powers do not work there; the Output Log says so.
  • Glide: the Glide power must be worn and switched on (power button) and Can Glide ticked.
