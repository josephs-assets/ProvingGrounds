Recipe 4: My own wall-run animation in my Anim Blueprint

Goal: your own clip plays on the wall and none of the kit's. Route: B with Animation Mode = External.

Steps

  1. Keep every Anim Set away from the hero: an empty character Anim Set falls back to the active theme's Anim Set (both shipped themes use DA_HeroActions), whose spin, slide, slam and double-jump clips then play on Action Slot. For none of the kit's clips, duplicate your theme, clear the copy's Hero > Anim Set and select the copy on the level's BP_Control > 3 Theme, with the character's own Anim Set (Class Defaults > Corridor | Animation) left empty.
  2. In your Anim Blueprint, Update Animation: get your Corridor Character, call Get Corridor Action, store it in a variable.
  3. In the AnimGraph add a state Wall Run entered when the variable equals Wall Run; the exit rule is "not Wall Run".
  4. Blend inputs: Is Wall On Right (mirror the pose) and Is Wall Run Ending (play the fall-off), both on the character's movement component.
  5. For sounds bind On Action Started / On Action Ended in the character's Event Graph.

The same pattern for the other mechanics:

Mechanic Action value Extra getters to blend
Slide, Crouch Slide, Crouch -
Slam Slam -
Rope Swing Rope Swing Get Rope Climb, Get Rope Sway
Grind Rail Grind Rail, Rail Hang Get Rail Lean, Get Hang Blend, Get Rail Swing
Mount Mount the mount's Get Speed, Is Boosting
Glide, Cyclone Glide, Cyclone -

A Slot node in your Anim Blueprint is only needed when you do use the kit's clips.

You should see

  • Your wall-run clip plays on the wall, nothing of the kit's on the mesh, and locomotion comes back on On Action Ended.

If it does not work

  • An Anim Set still reaches the hero (on the character or, when that is empty, on the active theme): its clips play on the Action Slot on top of yours.
  • The state compares the wrong value: print Get Corridor Action to the screen to see it change.
  • You read the action in the Animation thread without copying it: store it in Update Animation first.
