Corridor Platformer kit + ALS-Refactored (sample source)

Two classes you copy into your own C++ game module. They are not a module of the kit: ALS-Refactored is not part of the kit, and Fab builds every module a product ships. Tested with ALS-Refactored tag ue-5.7 (commit 3268c12a20) on Unreal Engine 5.7.

file what it is
AlsCorridorMovementComponent.h ALS's movement component + the kit's movement solver: rails, wall runs, ropes, the slide speed
AlsCorridorCharacter.h / .cpp ALS's example character + the kit's Corridor Hero component, double jump on ALS's jump input, spin / slide inputs

ALS keeps its locomotion, animation, camera, input, mantling and rolling. The kit adds crates, enemies, checkpoints, kill volumes, the double jump, spin, slide, slam and rail grinding.

Steps and measured results: BUYER_QUICKSTART_INTEGRATION.md, section "ALS-Refactored".

Turn mechanics off: the Corridor Hero component has a 5. Abilities block (Can Double Jump, Spin, Slide, Slam, Wall Run, Rope Swing, Grind Rail) and the node Set Ability Enabled. Wall run, rope and rail take the same switch, on this sample too. See Abilities and Actions.
